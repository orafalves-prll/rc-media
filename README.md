# rc-media

Hospedagem pública das imagens dos posts da **Recupera Cripto**.

Este repositório existe por um motivo técnico: a Graph API da Meta baixa a imagem
sozinha, sem autenticação, e por isso precisa de uma URL pública. O conteúdo e a
automação ficam no repositório privado `recuperacripto-instagram`, que empurra
para cá apenas a imagem do dia, segundos antes de publicar.

Nada aqui é editado à mão.
